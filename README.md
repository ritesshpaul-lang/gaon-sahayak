# Gaon Sahayak
**Multilingual AI Rural Service & Opportunity Navigator**

A prototype that helps rural citizens discover schemes, scholarships, jobs, skills and essential services through a simple multilingual interface.

## Run
Open `index.html` in a modern browser. No server or API key is required.

## Features
- Need-based discovery
- Location input
- Education, jobs/skills, agriculture, women/livelihood and essential services
- Hindi/English interface
- Conversational assistant prototype
- Sample data and test cases

## Architecture
Browser UI -> need/location input -> rule matching -> curated data -> recommendations -> assistant layer.
Production can add a backend, verified official sources, eligibility engine, GIS and an LLM API.

## AI disclosure
This prototype uses rule-based conversational logic and AI-assisted development. It does not call an external AI API. Any production LLM integration should be disclosed with its actual provider and contribution percentage.

## Disclaimer
Independent prototype; not an official Government of India/Jharkhand service and does not guarantee eligibility or approval.
